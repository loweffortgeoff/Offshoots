# Home Screen Widgets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a medium and a small Home Screen widget for revisits due, a Log link and a Hindsight tile, with one shared in-app router.

**Architecture:** The app writes a small `widget-summary.json` into a new App Group container whenever the journal or the Hindsight ownership changes. A new WidgetKit extension reads only that file. Every widget tap is a URL that the app turns into an `AppRoute`. Notification taps use the same route.

**Tech Stack:** SwiftUI, WidgetKit, Observation, Swift Testing. iOS 18.6 minimum.

**Spec:** `docs/superpowers/specs/2026-11-21-widgets-design.md`

## Global Constraints

- iOS 18.6 deployment target for the app and the extension. No iOS 27.1 API in this work.
- App Group: `group.com.geoffrey.silva.Offshoots`. Widget bundle ID: `com.geoffrey.silva.Offshoots.Widgets`. Xcode automatic signing may create both (Geoff approved 2026-11-21).
- Summary file name: `widget-summary.json`, written atomically. Model version `1`.
- Summary content: every due decision (no cap) plus the next 10 upcoming ones. Titles, IDs and due dates only. No notes, answers or outcomes.
- URLs: `offshoots://log`, `offshoots://decision/<uuid>`, `offshoots://revisits`, `offshoots://hindsight`.
- Decision titles in the medium widget use `.privacySensitive()`. The small widget shows no titles.
- No StoreKit or FoundationModels in the extension. The extension shows no generated text.
- Do not change the shared scheme's Run action, `selectedTab`'s default, or the launch arguments (CLAUDE.md "Never commit"). Revert the scheme `version` 1.7 → 1.3 change if Xcode makes it.
- Work on branch `dev/widgets`. Claude commits; Geoff pushes.
- Tests: run only the covering class with `-only-testing:OffshootsTests/<Suite>`, `-parallel-testing-enabled NO`, `-collect-test-diagnostics never`, on this run's simulator (`id=<UDID>`). Full suite only before the merge to `main`.

Test command used below (`$UDID` from `.claude/skills/verify-offshoots/verify.sh sim` after `verify.sh up`, with a unique `RUN_ID`):

```
DEVELOPER_DIR="/Applications/Xcode.app/Contents/Developer" xcodebuild -project Offshoots.xcodeproj -scheme Offshoots -destination "id=$UDID" -parallel-testing-enabled NO -collect-test-diagnostics never test -only-testing:OffshootsTests/<Suite>
```

## Review Focus

1. **A widget shows a decision that was deleted or resolved since.** A tap on `offshoots://decision/<id>` with an unknown ID opens the Decisions list root, with no crash and no empty detail. Task 1 pins this with `DecisionRoute.path(for:in:)`.
2. **Cold launch from the Hindsight tile before StoreKit answers.** An owner must never see the purchase sheet. Task 1 pins this with `HindsightRouteTarget.resolve` returning `.wait`.
3. **Missing, corrupt or future-version summary file** (first install, a crash mid-write, a downgrade). The widget shows the empty state and does not crash. Task 2 pins this with `WidgetSummary.decode`.
4. **A review date later today.** It counts as due today, the same as in the app (start-of-day rule). A resolved decision with no revisit date is not in the summary. Task 2 pins both.
5. **Restore failure.** While `recoveryError` is set, the summary is not overwritten, so the widget keeps the last good data. Task 3 pins this.

```swift
enum DueDay {
    static func isDue(_ date: Date, asOf now: Date, calendar: Calendar = .current) -> Bool  // startOfDay(date) <= now
}
struct WidgetSummary: Codable, Equatable {
    static let currentVersion = 1
    static let fileName = "widget-summary.json"
    static let appGroup = "group.com.geoffrey.silva.Offshoots"
    static let upcomingLimit = 10
    var version: Int
    var hindsightOwned: Bool
    var items: [Item]                       // dueDate ascending
    struct Item: Codable, Equatable, Identifiable { var id: UUID; var title: String; var dueDate: Date }
    static let empty: WidgetSummary         // version 1, not owned, no items
    func due(asOf now: Date) -> [Item]
    func upcoming(asOf now: Date) -> [Item]
    func refreshDates(after now: Date, limit: Int = 5, calendar: Calendar = .current) -> [Date]  // start of each later day an upcoming item becomes due
    static func decode(_ data: Data) -> WidgetSummary?   // nil on bad JSON or version != 1
    func encoded() throws -> Data                        // ISO 8601 dates
    static var containerFileURL: URL? { get }            // FileManager group container + fileName
}
```

**Interfaces:**
- Consumes: `WidgetSummary` (Task 2).
- Produces:

```swift
@MainActor final class WidgetSummaryWriter {
    init(fileURL: URL?, reload: @escaping () -> Void = { WidgetCenter.shared.reloadAllTimelines() })
    /// Owned flag starts from the file already on disk (false if none), so an unresolved launch keeps the last known value.
    func update(decisions: [Decision], blocked: Bool, now: Date = .now)
    func update(hindsightOwned: Bool)   // call only after ownership has resolved
}
```

A write happens only when the encoded data differs from the last write. Each write calls `reload()` once. `blocked == true` writes nothing.
